# SaltyClaims documentation

SaltyClaims is a Paper Minecraft plugin intended to provide lightweight land claims with native claim flags. It is currently a project scaffold; gameplay features have not been implemented.

- [Code documentation](code-documentation.md): source layout, lifecycle, build configuration, and implementation status.
- [Commands and permissions](commands-permissions.md): available commands and permission nodes.
- [Storage design](storage-design.md): planned single-server persistence and save behavior; not yet implemented.
- [Plugin plan](plugin-plan.md): claiming, future 3D children, GP-style trust, native flags, and delivery milestones.

This directory is tracked in Git. Keep it aligned with the implementation; label proposed behavior explicitly. Local AI working notes belong in the ignored root `AI/` directory.
